# CHAIN DRIFT title logo prompt

- Generator: Codex built-in `image_gen`
- Final target: 128×24 transparent PNG
- Hardware direction: circa 1979–1981 fixed-screen arcade graphics, designed
  around an 8×8 tile grid and a four-colour object palette
- Exact text: `CHAIN DRIFT`

## Prompt

Create a single compact horizontal pixel-art wordmark reading exactly
“CHAIN DRIFT”. Build the hard-edged letters from relay-board traces and small
four-prong electrical relay nodes. Use chunky custom 8×8-tile-style bitmap
lettering with square pixels, stepped diagonals, and broad simple colour
clusters. A subtle stagger through the letters suggests a chain reaction
drifting sideways.

Keep the title on one line and fully legible at very small size. Use only dark
electric blue, bright cyan, a very small yellow signal spark, and a tiny red
ignition point. Generate it on a perfectly flat `#00ff00` chroma-key
background.

Avoid antialiasing, bloom, gradients, bevels, metallic rendering, 3D
extrusion, scanlines, CRT curvature, frames, drop shadows, mascots,
illustrative explosions, chain-link clichés, watermarks, and modern esports
typography.
